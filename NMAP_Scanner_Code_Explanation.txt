====================================================================
EXPLANATION OF SCANNER.PY (NMAP NETWORK RECONNAISSANCE SCRIPT)
====================================================================

1. IMPORTING MODULES
--------------------------------------------------------------------
import os
import subprocess

- os: A built-in Python module used to interact with the operating 
  system. Here, we use it to check if files exist on your hard drive.
- subprocess: A built-in module that allows Python to run external 
  command-line programs (like Nmap) and capture their text output.


2. DEFINING THE MAIN FUNCTION & FINDING NMAP
--------------------------------------------------------------------
def run_scan():
    possible_paths = [
        r"C:\Program Files\Nmap\nmap.exe",
        r"C:\Program Files (x86)\Nmap\nmap.exe"
    ]

- def run_scan(): Groups all our scanning logic into a reusable 
  function.
- possible_paths: A list containing the two standard folders where 
  Windows installs Nmap (64-bit and 32-bit Program Files). The 'r' 
  before the quotes stands for "raw string," preventing Python from 
  misinterpreting backslashes (\).


3. VERIFYING NMAP INSTALLATION
--------------------------------------------------------------------
    nmap_path = None
    for path in possible_paths:
        if os.path.exists(path):
            nmap_path = path
            break
            
    if not nmap_path:
        print("[-] Error: nmap.exe could not be found automatically.")
        print("Please verify where Nmap is installed on your computer.")
        return

- The 'for' loop checks each path in our list using os.path.exists().
- As soon as it finds the valid path, it saves it to 'nmap_path' and 
  stops checking ('break').
- If Nmap isn't found in either folder, it prints a helpful error 
  message and exits the function cleanly ('return') instead of 
  crashing with a Python traceback.


4. BUILDING THE NMAP COMMAND
--------------------------------------------------------------------
    target = "127.0.0.1"
    command = [nmap_path, "-sS", "-sV", target]

- target: Sets the IP address to scan. "127.0.0.1" is your local 
  loopback address (your own computer), making it safe to test.
- command: A list representing the terminal command to execute:
  * nmap_path: The full path to nmap.exe.
  * "-sS": Tells Nmap to perform a TCP SYN (stealth) scan.
  * "-sV": Tells Nmap to probe open ports to determine service and 
    version info.
  * target: The destination IP address.


5. EXECUTING THE SCAN & HANDLING ERRORS
--------------------------------------------------------------------
    try:
        result = subprocess.run(command, capture_output=True, text=True, check=True)
        print("\n--- Scan Results ---")
        print(result.stdout)
    except subprocess.CalledProcessError as e:
        print(f"[-] Nmap ran into an error:\n{e.stderr}")

- try / except: A safety block that catches errors if Nmap fails 
  during execution (for example, if it lacks administrator rights).
- subprocess.run(...): Executes the Nmap command.
  * capture_output=True: Saves everything Nmap prints to the terminal 
    so Python can read it.
  * text=True: Formats the output as readable text instead of raw 
    computer bytes.
  * check=True: Triggers the 'except' block if Nmap returns an error 
    code.
- result.stdout: Contains the standard text output of the scan, 
  which is then printed to your screen.


6. SCRIPT ENTRY POINT
--------------------------------------------------------------------
if __name__ == "__main__":
    run_scan()

- This standard Python boilerplate ensures that run_scan() only 
  executes when you run this file directly (e.g., `python scanner.py`), 
  and not if you import this file into another Python script later.
